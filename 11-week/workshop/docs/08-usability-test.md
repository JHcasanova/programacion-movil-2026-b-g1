# CP8 · Prueba de usabilidad

## Tareas

1. Encuentre el sabor Fresa de temporada, revise su información, elija dos bolas
   con topping de chocolate y añádalo al carrito.
2. Desde el carrito, intente confirmar el pedido primero con un nombre de una
   sola letra, corrija el error y complete el pedido simulado.
3. Encuentre el pedido recién creado y abra su pantalla de seguimiento.

Las dos personas deben realizar las tareas sin recibir instrucciones adicionales.
El tiempo se mide desde que leen cada tarea hasta que la completan o abandonan.
